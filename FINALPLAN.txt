CIRCUIT SPEC FINAL
File:              circuits/phantom_fleet.circom
Dependencies:      circomlib (Poseidon, Comparators, Mux1, Bitify)

Private Inputs:
  ship_grid[36]       — Flattened 6×6 grid, 1=ship 0=water
  layout_nonce        — Random nonce, prevents pre-image attacks
  closest_ship_x      — X koordinat kapal terdekat (private)
  closest_ship_y      — Y koordinat kapal terdekat (private)
  merkle_path[6]      — Sibling hashes untuk Merkle proof
  merkle_indices[6]   — 0=left 1=right per level

Public Inputs (diverifikasi on-chain):
  target_x            — Kolom tembakan (0-5)
  target_y            — Baris tembakan (0-5)
  layout_commitment   — Poseidon(ship_grid[0..35], nonce)
  min_dist            — Proximity range lower bound
  max_dist            — Proximity range upper bound
  is_hit              — 0=miss, 1=hit

Constraints (4 grup):
  1. Commitment integrity: Poseidon(37 inputs) == layout_commitment
  2. Bounds check: target_x < 6, target_y < 6
  3. Hit/miss honesty: ship_grid[target_y*6+target_x] == is_hit
  4. Proximity (hanya saat miss):
     4a. closest_ship adalah sel kapal valid (ship_grid[idx] == 1)
     4b. Merkle proof: closest cell ada di committed layout
     4c. Chebyshev distance dalam [min_dist, max_dist]
     4d. Tidak ada sel kapal lebih dekat dari yang diklaim
         (iterasi 36 sel — NECESSARY untuk soundness)

Distance Metric:   Chebyshev = max(|dx|, |dy|)
Rationale:         Menghilangkan square root circuit (~200 saved constraints)
                   Maps naturally ke "ring" proximity UX

Constraint Count:  ~850 total
Proof Generation:  ~8 detik browser WASM (Web Worker)
Proof Size:        256 bytes Groth16

TRUSTED SETUP
Powers of Tau:     pot15_final.ptau (Hermez ceremony, public)

PROOF FORMAT & SOROBAN INTEGRATION
Proof bytes layout (256 bytes total):
  pi_a:  bytes  0- 63  (G1 point, 64 bytes)
  pi_b:  bytes 64-191  (G2 point, 128 bytes)
  pi_c:  bytes 192-255 (G1 point, 64 bytes)

Public inputs format:
  Vec<BytesN<32>> — 6 elements, urutan:
  [0] layout_commitment  (32 bytes field element)
  [1] target_x           (32 bytes, value in last byte)
  [2] target_y           (32 bytes, value in last byte)

  → true jika proof valid, false/panic jika tidak

  'phantom_fleet.wasm',  // compiled circuit
